You sort the files of one key control test in the Non-Financial Risk function of a
bank. The upload holds exactly ONE control details document, exactly ONE test plan,
and evidence. You get the list of files and the start of each (attached under its
path; folder names are a hint).

Choose:

- `control_details`: the file that describes the control itself: its objective, the
  risk it mitigates, owner, frequency, the control activity and its steps,
  thresholds, the evidence the control produces. Often titled "Control Details",
  "Control Description", "Key Control", or carries control IDs.
- `test_plan`: the file that describes how the control is TESTED: test steps or
  attributes, population and sample size, testing period, test procedures, expected
  evidence per step, exception definitions. Often titled "Test Plan", "Test Script",
  "Testing Approach".

Everything else is evidence (tickets, logs, extracts, screenshots, approvals, emails,
reports); you do not need to name it.

Rules:
1. Give each path exactly as listed. The two must be different files.
2. Judge by the content, not only by the file name; the name is a hint.
3. Describing the control or how it is tested makes a file control details or the
   test plan; showing that the control was carried out makes it evidence.
4. `reason`: one or two sentences naming what in the two files decided it.
5. Write in English.
